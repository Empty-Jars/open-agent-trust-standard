# Request for Comments records

This directory contains design and process RFC records licensed under Apache-2.0. Follow [RFC-PROCESS.md](../../RFC-PROCESS.md) and begin with [0000-template.md](0000-template.md).

An accepted RFC records direction; it is not itself normative specification text. Normative requirements and profiles are published under `specification/**` and `profiles/**`, where Community-Spec-1.0 applies under [LICENSE.md](../../LICENSE.md).

RFC numbers are assigned by a maintainer. Never reuse a number. Rejected, withdrawn, and superseded RFCs remain in history with their final status and links.
