# Foundation Roadmap

## Phase 0 — Charter and stewardship

- Confirm neutral name and conduct conflict search.
- Approve specification/code licenses and contribution terms.
- Obtain guidance on descriptive trademark references.
- Appoint interim specification, mission/theology, security/privacy, adopter, builder, and conformance stewards.

## Phase 1 — Use cases and risks

Document adopter, builder, and agent use cases; authority boundaries; private and safeguarding data; hiring needs; failure modes; threats; and revocation requirements.

## Phase 2 — Draft 0.1

- Core agent manifest
- Identity/accountability model
- Capability/permission model
- Ministry trust declarations
- Privacy/safeguarding profile
- Provenance/audit profile
- Service/hiring declarations
- Conformance levels and evidence model

## Phase 3 — Schemas and tests

Publish machine-readable schemas, validator, positive/negative fixtures, signed attestations, versioning, expiry, revocation, and at least two independent framework adapters.

## Phase 4 — Pilots and 1.0

Pilot with ministries, institutions, individuals, and independently built agents. Version 1.0 requires interoperability, security/privacy review, governance, appeals, migration, and public limitations.
