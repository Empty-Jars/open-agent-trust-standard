# ADR 0002: Separate trust claims from evidence

- Status: Accepted

## Decision

The standard distinguishes self-declared, sponsor-attested, technically tested, independently reviewed, and deployment-approved claims. It does not define one universal trust badge or score.

## Consequence

Every conformance result must identify the agent/version, profile/version, evidence, issuer/reviewer, date, expiration, exceptions, and revocation status.
